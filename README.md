# kickstartmac.nvim

Personal [Neovim](https://neovim.io) configuration, based on
[kickstart.nvim](https://github.com/nvim-lua/kickstart.nvim) and customised for
macOS.

This is a starting point for a Lua-based Neovim setup — fork it and adjust
`init.lua` to taste. Not a general-purpose distribution; it reflects one
person's editor preferences.
